about=Pick a folder of drone photos, tick what you want, click Process. The plugin shows the expected processing time, runs the job in the background while you keep working, and loads the styled results (orthophoto, DSM, DTM, point cloud) into your project. Everything runs on your own computer; photos never leave it. External dependency: the processing is done by OpenDroneMap software (AGPL v3), which the plugin does not include. On Windows the plugin offers to download the official OpenDroneMap installer (about 234 MB, from github.com/OpenDroneMap/ODM/releases) on first use and installs it for the current user, without administrator rights; it then runs as a separate program. On macOS and Linux, install Docker; the plugin then starts a NodeODM engine in Docker for you. A NodeODM engine on another computer can be used instead. This plugin is an independent project and is not affiliated with or endorsed by OpenDroneMap.
